# NLT Racing Overlay - Instruções do Projeto

Este projeto é o NLT Racing Overlay, desenvolvido em Java Spring Boot.

## Regras obrigatórias

- Nunca alterar arquivos sem antes explicar o plano.
- Nunca quebrar endpoints existentes.
- Nunca renomear controllers, services, DTOs, widgets ou rotas sem avisar antes.
- Não alterar dados brutos vindos da API do Le Mans Ultimate.
- Recalcular somente dados derivados quando isso for explicitamente pedido.
- Reutilizar services existentes antes de criar novos.
- Manter compatibilidade com Eclipse.
- Manter arquitetura baseada em widgets independentes.
- Explicar alterações importantes linha a linha quando solicitado.

## Estrutura esperada

- Backend em Java Spring Boot.
- Frontend dos widgets em HTML, CSS e JavaScript.
- Widgets usados no OBS via Browser Source.
- OBS roda no PC de stream, não no PC de jogo.
- Projeto aberto no Eclipse, mas Claude Code usado pelo terminal.

## Fluxo de trabalho

Antes de implementar qualquer coisa:

1. Ler a estrutura do projeto.
2. Identificar arquivos envolvidos.
3. Explicar o plano.
4. Aguardar minha aprovação.
5. Só então alterar arquivos.
